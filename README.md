# Drive a Car — Neon Circuit

A top-down arcade driving game in a single HTML file. No build step, no dependencies: open `index.html` in a browser and drive.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Gas | `W` / `↑` | GAS |
| Brake / reverse | `S` / `↓` | BRAKE |
| Steer | `A` `D` / `←` `→` | ◀ ▶ |
| Handbrake drift | `Space` | DRIFT |
| Nitro boost | `Shift` / `E` | NOS |
| Day / night | `N` | |
| Mute | `M` | |
| Restart | `R` | |

## Features

- Spline race circuit with curbs, neon edge lights, street lamps and a start gantry
- Night mode with real headlight cones and lamp lighting (toggle with `N`)
- Drift physics with skid marks and tyre smoke, plus nitro with flames and speed lines
- Lap timer, best lap, minimap, speedometer with gears
- Procedural engine and tyre sounds (Web Audio, no audio files)
- Works on desktop and mobile (on-screen controls)

## Play online

Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and the game will be live at `https://tomobao.github.io/Drive-a-Car/`.
